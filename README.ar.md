# السبورة (Whiteboard)

[English](README.md) · **العربية**

سبورة بيضاء مجانية وخفيفة لنظام ويندوز، بلوح **لا نهائي**، صُمّمت للمعلمين. اكتب وارسم وأضف الأشكال والصور، واستخدم أدوات الرياضيات المدمجة. الواجهة عربية أولاً (من اليمين إلى اليسار) وتتحول إلى الإنجليزية بنقرة واحدة.

## ماذا تقدّم؟
- **لوح لا نهائي:** تحريك وتكبير بلا حدود، مع أقلام وأشكال ونصوص وصور.
- **أدوات رياضيات:** مسطرة ومنقلة ومحاور إحداثية ورسم الدوال.
- **قائمة النقر الأيمن:** نسخ وقص وحذف وتكرار وترتيب العناصر وتدوير.
- **خطوط إرشاد ذكية:** تلتصق العناصر بمنتصف الشاشة وببعضها أثناء السحب والتدوير، كما في Word وPowerPoint.
- **مؤشر ليزر:** دائرة حمراء شفافة تُري الطلاب موضع الفأرة (Ctrl+L)، وتظهر أيضاً في تسجيلات الشاشة مثل OBS.
- **وضع فاتح ووضع داكن**، وتصدير إلى صورة أو PDF.

## البدء السريع (دون أي خبرة برمجية)
تحتاج فقط إلى ويندوز 10 أو 11، ولا حاجة لتثبيت أي شيء آخر.
1. اضغط الزر الأخضر **Code** في هذه الصفحة، ثم **Download ZIP**، وفك الضغط.
2. اضغط مرتين على **`build.bat`**. يبني البرنامج خلال ثوانٍ بمترجم موجود أصلاً في ويندوز.
3. افتح **`bin\Whiteboard.exe`**. هذا هو البرنامج، ويمكنك نسخه إلى أي مكان.

إذا ظهر خطأ، انسخ نصه وافتح Issue في هذه الصفحة.

## اختصارات لوحة المفاتيح
| الإجراء | الاختصار |
|---|---|
| المساعدة | F1 |
| تراجع / إعادة | Ctrl+Z / Ctrl+Y |
| نسخ / لصق / تكرار | Ctrl+C / Ctrl+V / Ctrl+D |
| حفظ / فتح | Ctrl+S / Ctrl+O |
| تصدير صورة أو PDF | Ctrl+E |
| إدراج صورة | Ctrl+I (أو لصق / سحب وإفلات) |
| تكبير وتصغير | Ctrl + عجلة الفأرة |
| ملاءمة المحتوى / الحجم الأصلي | F / Ctrl+0 |
| تدوير 90° | Ctrl+R |
| للأمام / للخلف | Ctrl+] / Ctrl+[ |
| تشغيل/إيقاف الليزر | Ctrl+L |
| ملء الشاشة | F11 |
| نافذة جديدة / إغلاق النافذة | Ctrl+N / Ctrl+W |

## للمطورين
- اللغة والأدوات: **C# 5** وWinForms وGDI+ (واجهة مرسومة يدوياً)، بلا مكتبات خارجية، ويُبنى بـ `csc.exe` من .NET Framework.
- كل شيء داخل عنصر واحد اسمه `Board`، مقسّم إلى ملفات `partial class` حسب المسؤولية ضمن `src/Board/`.
- رقم النسخة ثابت واحد في `src/App/AppInfo.cs` (MAJOR.MINOR.PATCH)، والتغييرات في `CHANGELOG.md`.
- الأمر `python tools/check_all.py` يشغّل فحوصات اتساق المشروع.
- تفاصيل أكثر: `docs/ARCHITECTURE.md` و`docs/CODE_MAP.md` و`docs/VERSIONING.md`.
